Сделай план страниц для дальнейшей генерации инфографики из DOCX.

Важно: не распределяй текст приблизительно. Сначала выполни анализ документа.

Шаг 1. Разбор DOCX

Сначала выдели реальные блоки документа:

- заголовки разделов;
- подразделы;
- таблицы;
- схемы;
- кодовые блоки;
- вопросы и ответы.

Для каждого блока укажи:
- название;
- начало и конец блока;
- количество слов.

Не считай «примерно». Считай фактический объём каждого блока.

Шаг 2. Формирование страниц

Только после подсчёта блоков создай страницы.

Для каждой страницы укажи:

Page N:
- какие конкретно блоки входят;
- где начинается и где заканчивается текст;
- количество слов на странице.

Формат:

Page 1:
Блок 1 (полностью)
Блок 2 (до пункта X)
Слов: XXX

Page 2:
Блок 2 (остаток)
Блок 3 (начало)
Слов: XXX

Шаг 3. Проверка распределения

Проверь:

Page 1 + Page 2 + ... + Page N = общий объём документа.

Не допускай:
- страницу на 150 слов и страницу на 500 слов без причины;
- перенос темы в середине логического объяснения;
- перенос схемы отдельно от текста, который её объясняет.

Цель:
- страницы примерно одинаковые по объёму;
- разница между страницами желательно не больше 30–50 слов;
- страницы с большими схемами могут иметь меньше текста.

Учитывай:
мало слов + большая схема = нормальная заполненность страницы.

Шаг 4. Границы для генерации

После плана добавь отдельный блок:

"Ограничения генерации"

Запрещено использовать следующие разделы.

Не переносить текст между страницами.
Не добавлять свои объяснения.
Не сокращать предложения.
